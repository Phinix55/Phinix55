### ✦ The Blueprint (About)

Hi, I'm Pratik. I'm a 23-year-old software engineer and designer. 

I love crafting pixel-perfect, immersive mobile and web apps that break away from generic "AI slop". I heavily leverage modern tools to "vibe code" and move insanely fast, but **I never code blindly**.

I sit at the intersection of product design and heavy engineering. I map out the architecture, design the logic, and set strict guardrails first—then I simply let the editor handle the heavy typing. From interactive 3D interfaces (WebGL/Three.js) and pixel-perfect mobile UIs, to complex backend integrations, I know exactly what's happening under the hood.
